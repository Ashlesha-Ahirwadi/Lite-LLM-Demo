  1. In Through gateway — remembers mode, tell it something: "My name is Ashlesha."
  2. Switch to Direct to model — forgets and ask "What's my name?" → it won't know.
  3. Switch back to Through gateway — remembers and ask again → it remembers.

Watch the inspector panel — the browser sends the same short message both times. The only thing that changes is whether the gateway is on.
